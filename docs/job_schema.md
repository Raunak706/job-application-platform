# Canonical Job Schema

This schema defines the normalized representation of a job posting used by the platform.

## Identity

- `id`
  - Internal UUID generated by our system.

- `source`
  - Origin of the posting.
  - Examples: `greenhouse`, `lever`, `indeed`, `company_site`

- `source_job_id`
  - Job identifier provided by the source.

- `source_url`
  - URL where the posting was collected.

- `application_url`
  - Direct URL used to apply for the job.

## Company

- `company_name`
- `company_normalized_name`
- `company_domain`

## Job

- `title`
- `normalized_title`
- `description`
- `employment_type`
  - Examples: `FULL_TIME`, `PART_TIME`, `CONTRACT`, `INTERNSHIP`, `TEMPORARY`

- `experience_level`
  - Examples: `INTERN`, `ENTRY`, `MID`, `SENIOR`, `LEAD`, `MANAGER`, `UNKNOWN`

## Location

- `location_raw`
- `city`
- `state`
- `country`
- `remote_type`
  - `ONSITE`
  - `HYBRID`
  - `REMOTE`
  - `UNKNOWN`

## Compensation

- `salary_raw`
- `salary_min`
- `salary_max`
- `salary_currency`
- `salary_period`
  - `HOUR`
  - `MONTH`
  - `YEAR`
  - `UNKNOWN`

## Skills and Requirements

- `skills`
  - Normalized list of skills.

- `required_skills`
- `preferred_skills`

- `education_requirement`
- `years_experience_min`
- `years_experience_max`

## Dates

- `posted_at`
- `first_seen_at`
- `last_seen_at`
- `last_verified_at`

## Status

- `status`
  - `ACTIVE`
  - `STALE`
  - `CLOSED`
  - `UNKNOWN`

## Raw Data Linkage

- `raw_job_id`
  - Foreign key to original raw payload.

## Processing Metadata

- `normalized_at`
- `normalization_version`
- `content_hash`
